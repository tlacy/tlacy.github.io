BIM · AI Demo

The Plan → Reality → Intelligence loop on an OpenBIM backbone — grounded, governed, human-approved.

1 · Plan — load an OpenBIM model

Parse an IFC file (ISO 16739) in the browser with web-ifc. The AI reasons over the semantic model — objects, properties, relationships — not a flattened PDF.

2 · Validate — run IDS checks

IDS (Information Delivery Specification) = machine-readable requirements. Pass/fail is computed from the real model — the grounding the AI reasons over.

3 · Reality — DroneDeploy delta stub

Simulated reality capture. This is the connector seam where the DroneDeploy API returns georeferenced as-built progress, aligned to the model CRS via IfcMapConversion / IfcProjectedCRS (ISO 19650).

4 · Intelligence — summarize & propose issues

The intelligence layer turns grounded findings into proposed issues. Pluggable: a deterministic local summary, or the real DataGrid /converse agent via a backend proxy.

5 · Action — approve & emit BCF human-in-the-loop

Nothing writes back autonomously. You approve the issues, then export an open-standard BCF 2.1 file that any tool (Procore, ACC, Solibri) can import. Write-back to Procore/DataGrid is the connector seam.

Open standards: IFC (ISO 16739) · IDS · BCF · ISO 19650. Parsing by web-ifc (WASM). DroneDeploy & DataGrid integrations are labeled connector stubs in this build.
